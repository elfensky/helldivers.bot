<flagged_assumptions>
## Flagged Assumptions (edge probe — spec-less fallback)

- **STAB-01 / unclassified — unresolved.** The edge probe returned "unclassified — review manually" for STAB-01. Recorded here rather than dropped. Reviewed manually during planning: the requirement's edge dimension is the *timezone axis* (which offsets straddle a date boundary relative to the UTC server render), and it cannot be exhaustively enumerated in a test suite — hence the `backstop` truth above covering "any IANA timezone". Two zones are exercised concretely (Europe/Warsaw, the reporter profile; America/Los_Angeles, the opposite sign). A reviewer who can name a third boundary condition worth pinning should add it to the sweep table.
- **Sweep completeness is not machine-provable.** The static inventory in Task 1 is a grep over a hand-listed set of identifiers. A divergence introduced by a transitively imported helper that reads the environment without matching any grepped token would be missed by Input B and caught only by Input A (the browser run). This is why the plan requires the browser reproduction to be green in *both* directions, not the grep alone.
</flagged_assumptions>
