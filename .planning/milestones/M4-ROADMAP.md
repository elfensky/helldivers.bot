# Milestone M4: Developers can use a public API

**Status:** ✅ SHIPPED 2026-06-23
**Phases:** 0.13–0.14

## Overview

**Milestone goal:** Developers query versioned `/api/v1/h1` endpoints with API keys, rate limits and an OpenAPI document, released to `main` as v0.59.0.

This milestone predates the GSD plan, which started on 2026-08-29. It was recorded on 2026-11-09 from CHANGELOG.md and
GitHub milestone "Public API & Config", so it has no plan, summary or requirements files.
