<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OG route -> external Umami instance | The route makes an outbound request to a third-party analytics host on the render path |
| Postgres -> OG data guard | `getCampaign()` results select which branch the unauthenticated request takes |
| Unauthenticated crawler -> telemetry volume | Request rate directly drives outbound analytics volume |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Denial of Service | Telemetry call on the render path | medium | mitigate | The call is fired without blocking the response (via `after()` or an unawaited promise) and `sendUmamiEvent` already swallows its own transport failure, so a slow or dead analytics host cannot stall or fail an image response |
| T-04-02 | Information Disclosure | Umami event data payload | medium | mitigate | The event data carries only the outcome and the failure stage — no request headers, no user agent, no IP, no database content. (Personal-data handling in analytics is canon GDPR territory covered by `/gsd-secure-phase`; not minted as a bespoke prohibition.) |
| T-04-03 | Repudiation | Silent data-fetch failure | high | mitigate | Task 2 adds a `reportError` call to the query-failure branch, which today returns the fallback with no telemetry at all — the exact reason the original freeze had no trail |
| T-04-04 | Denial of Service | Unbounded analytics volume from crawler traffic | low | accept | The success path is cached for 300 seconds by 01-03, so events fire at most once per cache window per edge; at ASVS L1 this bounded volume against a self-hosted analytics instance is an accepted cost |
</threat_model>

<flagged_assumptions>
## Flagged Assumptions (edge probe — spec-less fallback)

- **STAB-02 edge dimensions covered here.** The `unclassified` STAB-02 probe row is carried in plan 01-03's flagged assumptions; this plan closes its third dimension (edge-case map states) with three concrete fixtures. No separate probe row is owned by this plan.
- **`after()` support on an image-generation route is unverified at plan time.** `after()` is documented for Route Handlers and Server Components; whether Next 16 supports it inside a `opengraph-image` file convention export was not confirmed during planning. Task 1 requires the executor to check `node_modules/next/dist/docs/` and record the answer, with an unawaited call as the documented alternative. Flagged rather than assumed.
- **The rendered-vs-cached ratio is derived, not measured directly.** Event count equals invocation count only because the route cannot run on a cache hit. If a future change makes the route run on every request, the derivation silently becomes trivial rather than wrong — worth re-checking whenever the cache policy set in 01-03 changes.
</flagged_assumptions>
