## User Setup Required

**Critical — must happen before this branch merges to `develop`.** Arcane Git Sync deploys `deploy/staging/compose.yaml` on every commit to `develop`, and Swarm rejects the entire stack deploy if an `external: true` secret referenced in the compose file does not exist yet (`secret not found: helldiversbot_sentry_dsn`). Merging before the secret exists breaks the next staging deploy outright — not a degraded state, a failed one.

Create the Swarm secret on a manager, out of band, before merging this branch to `develop`:

```sh
printf '%s' "$SENTRY_DSN" | docker secret create helldiversbot_sentry_dsn -
```

Use `printf`, not `echo` — a trailing newline corrupts the DSN. Run on any of the three Pi managers (all nodes are managers, so any of them shows the same cluster).

Post-merge confirmation (human step, not automatable from this session): once the secret exists and the stack redeploys, staging server errors should appear in GlitchTip tagged `environment=staging`, with `server_name` naming the Pi node that produced them.
