# Players can build and share loadouts

## What you get

A player builds a loadout, sees its stats and shares it as a link with its own preview image, up to a full four-player squad. The URL format is fixed first, because shared links cannot be migrated. The milestone ends in a release to `main`.

## Where it stands

0 of 3 phases done.

## Done means

- 7. Loadout Foundation (Catalogs + Codec) — Item catalogs and the versioned shareable-URL hash format lock before any UI encodes against them
- 8. Loadout Builder Core — A player can build a loadout, see its stats, and share a link with a custom preview image
- 9. Loadout Enhancements & Squad Mode — Guides, favorites, account sync, accessibility, and a 4-player shareable squad loadout
