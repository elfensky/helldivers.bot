# The first site caches the war and draws the map

## What you get

The first site caches the Helldivers 1 API in Postgres, serves it again in the game's format, and shows the map, stats and timeline.

## Where it stands

Shipped 2025-12-09: 4 phases done.

## Done means

- 0.1. Base app — Next.js and Prisma run from a Docker image, with sign-in and an API-key dashboard (0.1.0–0.3.3) (completed 2025-05-19)
- 0.2. Rebroadcast API — `POST /api/h1/rebroadcast` serves `get_campaign_status` and `get_snapshots` in the game's format, with Swagger docs (0.4.0–0.4.1) (completed 2025-05-20)
- 0.3. Map, stats and timeline — A worker polls the HD1 API every 20 seconds, and players see the galaxy map, the stats and the war timeline (0.4.2–0.7.3) (completed 2025-06-24)
- 0.4. Landing page — The layout and the navigation are rebuilt around a real landing page (0.7.4–0.8.0) (completed 2025-12-09)
